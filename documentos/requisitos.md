# Requisitos do Sistema

## Requisitos Funcionais

- **RF01:** O sistema deve permitir o cadastro dos livros e suas características.
- **RF02:** O sistema deve permitir que o aluno responda ao questionário de preferências.
- **RF03:** O sistema deve identificar as preferências informadas pelo aluno.
- **RF04:** O sistema deve recomendar livros de acordo com as respostas do aluno.
- **RF05:** O sistema deve permitir pesquisar livros por título, autor e gênero.
- **RF06:** O sistema deve permitir filtrar livros por características.
- **RF07:** O sistema deve permitir que o aluno avalie os livros recomendados.
- **RF08:** O sistema deve registrar as avaliações realizadas.
- **RF09:** O sistema deve apresentar os livros mais bem avaliados.
- **RF10:** O sistema deve permitir que o bibliotecário cadastre, edite e remova livros.
- **RF11:** O sistema deve armazenar o histórico de recomendações.
- **RF12:** O sistema deve permitir visualizar informações detalhadas sobre cada livro.

## Requisitos Não Funcionais

- **RNF01 — Usabilidade:** O sistema deve possuir uma interface simples e fácil de utilizar.
- **RNF02 — Desempenho:** As recomendações devem ser apresentadas rapidamente após o questionário.
- **RNF03 — Segurança:** O acesso às funções administrativas deve ser protegido por login.
- **RNF04 — Confiabilidade:** O sistema deve armazenar os dados corretamente.
- **RNF05 — Disponibilidade:** O sistema deve estar disponível durante o funcionamento da biblioteca.
- **RNF06 — Compatibilidade:** O sistema deve funcionar em computadores, tablets e celulares.
- **RNF07 — Manutenibilidade:** O código deve ser organizado para facilitar futuras alterações.
- **RNF08 — Escalabilidade:** O sistema deve permitir o cadastro de novos livros e usuários sem prejudicar seu funcionamento.
- **RNF09 — Privacidade:** Os dados pessoais dos usuários devem ser protegidos.
- **RNF10 — Integridade:** As informações dos livros, usuários e avaliações não devem ser alteradas ou perdidas de forma indevida.
